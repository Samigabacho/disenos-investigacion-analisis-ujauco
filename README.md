# Material docente — Diseños de Investigación y Análisis Estadístico Aplicados a la Educación (Máster UJA–UCO)

Este repositorio publica el material en **GitHub Pages**.

## Estructura

- `docs/` contiene el sitio web (GitHub Pages).
  - `index.md`: portada y navegación.
  - `bloque-1.md`: Bloque 1.
  - `bloque-2.md`: Bloque 2.
  - `_config.yml`: configuración de Jekyll (tema *minima*).

## Publicación en GitHub Pages (recomendado)

1. Crea un repositorio en GitHub (p.ej., `disenos-investigacion-analisis-estadistico`).
2. Sube todo el contenido de esta carpeta al repositorio.
3. En GitHub: **Settings → Pages**
   - *Build and deployment* → **Deploy from a branch**
   - Branch: `main`
   - Folder: `/docs`
4. Guarda. La URL final tendrá el formato `https://<usuario>.github.io/<repo>/`.

## Edición

- Edita directamente los ficheros `.md` dentro de `docs/`.
- Si partes de un Word, lo ideal es convertir a Markdown (p.ej., con Pandoc) y después revisar el resultado.

## Notas

- Este sitio usa Jekyll (lo soporta GitHub Pages sin configuración adicional).
